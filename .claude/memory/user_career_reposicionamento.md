## Perfil identificado: Technical Product Owner / AI-Augmented Developer

Edu entregou um app desktop completo (Electron + SQLite + cloud + auto-update + PDF + 90 testes) em tempo que uma software house levaria meses. Fez isso guiando decisões de produto, revisando código gerado, fazendo QA, identificando bugs de produção e tomando decisões de arquitetura com contexto de negócio real.

Não é engenheiro clássico (não escreve cada linha à mão), mas entende profundamente o que o código faz, raciocina sobre tradeoffs técnicos, e conecta necessidade de negócio com solução técnica de forma direta.

**Categoria emergente:** AI-augmented developer / Technical founder. "Vibe coder" subestima. "No-code" não descreve — é código real.

## Cargos que descrevem o perfil

- **Technical Co-founder** — perfil padrão de cofundador técnico em startups early-stage

## Caminhos de carreira acionáveis

### 1. Ferramentas internas para PMEs (maior oportunidade imediata)
Centenas de negócios familiares e PMEs precisam de sistemas sob medida que não existem no mercado ou custam caro demais. Edu já provou que consegue entregar.
- **Ticket**: R$15–50k por projeto + manutenção recorrente
- **Diferencial**: entrega em semanas o que software house leva meses, com custo proporcional
- **Nicho quente**: moda, decoração, agro, serviços profissionais

### 2. Consultor de digitalização de operações
Entra no negócio, entende o processo, entrega sistema funcional. Vende resultado, não horas.

### 3. Technical Product Manager (empresa)
Em empresas de produto digital: fala com engenheiros na linguagem deles, prototipar hipóteses antes de gastar sprint, especificar requisitos com precisão técnica real.

### 4. Micro-SaaS / produto próprio
Solução Compras pode ser generalizada para outros setores com processo de compra similar (decoração, calçados, têxteis).
- 30 assinantes × R$500/mês = R$15k/mês recorrente
- Custo marginal próximo de zero após o produto estar pronto

## Evidência de portfólio

- **Solução Compras**: app desktop Windows completo, Electron + SQLite + Vercel + auto-update + PDF + projeções + 90 testes automatizados. Cliente real (Samuel Backes, rede de lojas de moda).
- **Keenfisher plugin**: plugin de treinamentos em domínio diferente (RH/capacitação). Prova que resolve *problemas de negócio* em múltiplos domínios, não só uma solução específica.

Transitar entre domínios diferentes é sinal de **generalista técnico** — o perfil mais valioso no ecossistema de ferramentas AI-first.
